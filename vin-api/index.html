R&R VIN API — Layer 2 MVP

VIN + door-jamb photo → whole car: exterior, interior, engine, mechanical. Standalone demo — no server, no other layer, nothing is charged. The VIN is decoded live by NHTSA (free); parts come from R&R's verified catalog (catalog.json, 4 vehicles, 37 part rows).

2 · Door-jamb label (optional — settles tires)

Photograph the label on the driver door jamb. The camera reads tire size, cold pressures, GVWR and build date. Check the values — correct anything misread — then run the lookup above. A confirmed tire size replaces the "variant ambiguous" tire answer.

Manual entries are labeled "manual entry (door-jamb label)" in the result. The photo never leaves this browser except to the OCR library's CDN download — no photo is uploaded to R&R.
